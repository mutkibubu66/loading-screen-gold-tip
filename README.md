A loading-screen tip in one line: the progress bar isn't stuck, it's just on a union-mandated break.

## The line

> Loading tip: the bar isn't stuck — it's on a union-mandated break. Please hold while it files the paperwork.

The joke treats the loading bar like a worker: when it stops moving, it hasn't crashed — it's taking the break it's owed, and the paperwork is the punchline. Everyone has stared at a frozen bar; giving it a labour dispute makes the wait feel absurd instead of annoying.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — one line, 108 characters, valid UTF-8 — and prints it to stdout.
